    Flash → SRAM takes one byte in two (even positions) from the 64 KB save.
    
SRAM → Flash does the reverse: writes each byte to the even positions of a 64 KB area, the rest set to 0xFF, as the cartridge expects.
    
Journal → normal rebuilds the save from the journal and writes it in the previous interleaved format.
